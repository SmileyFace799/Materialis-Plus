# Materialis Plus
This is a fork of Materialis with the intention of adding support for a few more materials. This is for a personal modpack, and there are currently no plans to develop this into a public mod.
Materialis is an addon for [Tinkers Construct](https://www.curseforge.com/minecraft/mc-mods/tinkers-construct), it adds more materials to craft tools with.

More information can be found [here](https://www.curseforge.com/minecraft/mc-mods/materialis).
